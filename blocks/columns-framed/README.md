# columns-framed

Custom **columns** block. 

## Authoring (Document Authoring)

Model: `standalone`

Block table with header `Columns Framed`, then one content row with one cell per column (2 or 3 cells), for example:

| Columns Framed | |
| --- | --- |
| cover image, then a paragraph with the Spotify link | bulleted tracklist |

Keep cell content as default content (image, paragraphs, lists, links). Empty cells are dropped. Rows with fewer or extra cells still render. The block is framed with a light border. Two-column tables split roughly 37.5% / 62.5% when the first column holds an image; 3-column tables use equal widths. Like the source table it never stacks: on small screens the columns narrow and images shrink (max-width 100%). Don't use this block for a single-cell table; use default content instead.
